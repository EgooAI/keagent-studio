## 1. 客户端下载与安装

AI来客桌面端支持 **Windows（x64）** 与 **macOS（Apple Silicon / Intel）**。安装包已内置本地视频合成工具（FFmpeg / FFprobe）与执行运行时，安装完成后无需再自行配置任何环境。

> 如果您还没有获取安装包，请先前往 [下载中心](/download) 查看当前版本状态与系统要求。

## 2. 登录工作台账号

打开 AI来客客户端后，使用管理员为您开通的账号与密码登录。

- **账号数据隔离**：您的房源库、开场视频、音色、任务记录与线索跟进均归属当前登录账号，不会与其他成员混用。
- **本机资料留存**：平台登录会话（抖音 / 小红书）、开场视频原片与本地渲染缓存保存在当前设备目录中，卸载重装或覆盖升级时会自动沿用既有目录。

## 3. 认识六个一级导航

进入工作台后，左侧固定提供六个核心入口，完整覆盖房产短视频营销全流程：

| 导航入口 | 核心用途 |
| --- | --- |
| **工作台** | 优先展示需要您审核文案或安排发布的待办任务，以及账号概况 |
| **房源中心** | 管理所有房源资料，支持房源号批量导入、Excel/CSV 导入、人工录入与全景图挂载 |
| **AI 视频工厂** | 多选房源批量创建独立视频任务、编辑审核口播文案、查看本机渲染进度 |
| **发布中心** | 预览验收成片，按抖音与小红书分别配置发布参数，核对草稿与正式发布记录 |
| **AI 获客** | 绑定已发布作品，持续监控评论并筛选高意向客户，编辑跟进话术与人工私信 |
| **设置** | 管理个人资料、开场视频库、本人音色复刻、平台账号绑定、积分兑换与主题配色 |

## 4. 首次出片推荐路径

1. 在 **房源中心** 添加 1 套房源，并为其准备好 2–7 张原始 VR 全景图。
2. 如需真人出镜，先在 **设置 → 开场视频库** 导入一段 2–30 秒的实拍 MP4（≤ 50 MB）。
3. 进入 **AI 视频工厂 → 新建视频**，勾选房源与搭配模式，选择公共音色或本人音色并提交生成文案。
4. 在任务列表中核对并编辑口播文案，确认通过后等待本机自动完成配音、运镜与字幕合成。
5. 成片完成后进入 **发布中心** 预览验收，再配置抖音或小红书任务。
