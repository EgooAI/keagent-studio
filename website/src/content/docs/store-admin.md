## 1. 为什么采用“桌面端 + 独立 Web 后台”分离架构

为了兼顾经纪人作业效率与门店运营安全，AI来客将两个端彻底隔离：

- **桌面客户端**：专供房产经纪人使用，不含任何管理员入口，界面清爽聚焦日常出片与获客。
- **独立 Web 管理后台**：仅通过独立网页访问，必须使用管理员账号登录，用于统一管理团队成员、公共资产与云端服务。

## 2. 门店管理员的核心管理能力

登录 Web 管理后台后，管理员可以一站式完成以下日常运营工作：

- **用户与设备管理**：创建并管理经纪人账号、查看账号登录状态与设备绑定情况，避免陌生人自助注册带来的安全风险。
- **公共模板与音色下发**：统一上架、更新或下架视频搭配模板与公共音色目录。桌面端会自动比对目录版本号并在本地增量同步，全店经纪人一键用上最新模板。
- **AI 服务配置与验证**：集中维护多模态文案模型与百炼语音服务的 API 凭证；更换密钥时后台会先用真实样例校验，验证通过后自动生效。
- **积分与兑换码管理**：配置各项云端 AI 调用单价、新用户赠送策略，批量生成积分兑换码或直接为门店经纪人账户充值，并查看完整流水与云端任务排查记录。
- **操作审计与异常排查**：工作台左侧集中展示待排查的云端任务，右侧汇总运营指标与配置缺项，重要后台操作均留存审计记录。

## 3. 部署与隔离说明

- 云端业务服务（Go + PostgreSQL）与认证服务支持单机服务器部署，通过 HTTPS（如 Caddy）对外提供稳定访问。
- 管理员与经纪人数据严格按 `owner_user_id` 隔离，跨账号资源访问会被服务端拒绝。
- 门店若有多名经纪人，无需为每人单独申请 AI 供应商 API Key，在后台统一配置并按积分分配额度即可。
