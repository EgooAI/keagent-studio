## 1. 绑定本机平台账号

在提交发布任务前，请先进入 **设置 → 平台账号**，选择抖音或小红书并在内置浏览器窗口中完成登录保存。

- 平台账号的登录会话仅保存在您的本机设备中，不会上传到云端服务器。
- 支持同一设备管理不同平台账号，发布任务按队列在本机有序执行。

## 2. 成片验收与双平台独立配置

视频工厂制作成功的成片会自动出现在 **发布中心**。点开成片详情可完整查看：

- 绑定的房源资料快照、当前文案修订、使用的音色与模板版本；
- 成片视频预览与生成的封面图。

同一条成片可以分别创建 **抖音** 与 **小红书** 两条完全独立的发布任务：

- **差异化运营**：可分别设置不同的发布账号、标题、正文描述、话题标签与封面。
- **互不干扰**：一个平台的发布状态或异常，不会影响另一个平台的执行。
- **公开发布确认**：从草稿或直接公开发布前，系统均会给出明确确认提示，防止误发。

## 3. 状态核对原则：绝不把未知当成功

AI来客严格区分不同阶段的平台结果：

| 状态 | 含义说明 | 是否计入“已发布过” |
| --- | --- | --- |
| **草稿已保存** | 内容已保存到平台草稿箱，尚未对外公开 | 否 |
| **结果待核对** | 平台返回超时或状态未明确，需人工确认，系统不会盲目重复提交 | 否 |
| **正式发布成功** | 已核对到平台正式发布记录 | 是 |

> 当目标平台暂不支持自动化草稿保存或遇到策略限制时，系统会提供清晰的**本地待发布包**（含成片、封面与复制好的标题文案），协助您快速完成手动发布。
