# KeAgent Studio 开发文档

KeAgent Studio 是面向房产经纪人的 AI 视频生产与营销桌面应用的工作名称。用户通过房源资料批量生成视频，审核文案，查看成片，提交各平台草稿或发布流程，并分析评论线索。客户端支持 Windows 和 macOS，另有 Go 云端服务、本地执行器和独立 Web 管理后台。

版本：V1 开发基线。整理日期：2026 年 10 月 30 日。

当前仓库仅包含开发文档，应用代码尚未创建。以下文档用于产品、前端、Go 后端、本地执行和测试协作，也可以作为开发 Agent 的任务依据。

## 已确认的开发基线

- 桌面端采用 Electron、React、TypeScript；云端采用 Go、Gin、PostgreSQL 与 S3 兼容对象存储；本地采用 Go Sidecar、SQLite、FFmpeg、FFprobe 和 Playwright 配套浏览器。
- 用户需要的本地执行环境随安装包交付；字体和模板等基础资源内置，新增资源从云端按需获取。
- 客户端固定六个一级入口：工作台、房源中心、AI 视频工厂、发布中心、AI 获客、设置。没有独立内容资产页面。
- 视频工厂为单页配置，只有纯口播、经纪人露脸两种模式。一次选择 N 套房源，生成一个批次和 N 个独立任务。
- 房源、视频模板和风格模板用大弹窗；提示词、声音和形象用下拉选择；文案审核可开启或关闭。
- 发布中心保留完整生产信息；同一成片的抖音、小红书任务和结果独立。平台草稿不等于正式发布。
- 首版不做套餐、支付、积分、复杂组织权限、专业剪辑时间轴、插件市场或 Redis。

## 使用规则

[原始需求讨论](https://chatgpt.com/share/6ae46246-77c0-83ee-878e-337879510e80)中较晚的用户确认覆盖较早方案。产品章节标注已确认范围，其余为实现这些需求补充的设计，不表示用户已经决定具体登录方式、供应商、操作系统最低版本或存储保留期限。

产品范围以第 01 章为准；状态、字段和接口以第 04 章为准；页面按第 03 章实现；工程边界按第 02 章实现；完成判断按第 05 章执行。出现跨章冲突应同步修正文档，不能让前端 Mock 和真实后端各用一套规则。

先完成可运行的 Mock 闭环，再逐模块接入真实能力。Mock 演示通过只说明交互可用；真实房源获取、声音克隆、数字人和平台操作必须单独验证。需要的外部能力不可用时，明确提供人工导入或待发布包等替代路径及剩余限制。

## 开始开发

从第 05 章 M0 开始：建立工作区、桌面壳和管理后台壳，固定共享类型与 Mock 接口，然后完成“房源中心 → 多房源视频生产 → 文案审核 → 发布中心”的完整链路。不要只实现首页，也不要在界面代码里直接执行系统命令或保存供应商密钥。

本次文档没有建立脚本或安装依赖。第 05 章中的启动、测试与打包命令是工程阶段应提供的约定；创建工程后再把实际可执行命令和部署配置补回本文件。
