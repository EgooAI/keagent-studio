# KeAgent Studio 开发文档

KeAgent Studio 是面向房产经纪人的 AI 视频生产与营销桌面应用的工作名称。用户通过房源资料批量生成视频，审核文案，查看成片，提交各平台草稿或发布流程，并分析评论线索。客户端支持 Windows 和 macOS，另有 Go 云端服务、本地执行器和独立 Web 管理后台。

版本：V1 开发基线。整理日期：2026 年 10 月 30 日。

仓库已有 Electron + React 客户端、独立 React 管理后台、SEO SDK/Next.js 认证服务和 Go/PostgreSQL 业务服务。两端通过 JWT 直接请求 Go，Go 使用 JWKS 独立验签并在 PostgreSQL 复核实时会话与权限；迁移期保留旧签名网关。已新增可实际执行的全景视频工作流：导入全景、分段文案审核、本机配音、按声音时长旋转、字幕合成和 MP4 导出。云端 AI、火山 TTS 与照片数字人适配器已接入配置检查，付费调用待凭证联调。启动方式见 [后端与桌面联调](docs/06-后端与桌面联调.md)，本次实现与限制见 [全景工作流](docs/09-panorama-workflow.md)。以下原有章节仍包含前端 Mock 阶段说明。

[完整阅读版](https://chatgpt.com/space/page_d0eb0ef5edc881919ee3018d5168da9d)已保存为私有 Page。后续开发以仓库文档为维护基线；Page 为本次整理的阅读副本。

## 已确认的开发基线

- 桌面端采用 Electron、React、TypeScript；云端采用 Go、Gin、PostgreSQL 与 S3 兼容对象存储；本地采用 Go Sidecar、SQLite、FFmpeg、FFprobe 和 Playwright 配套浏览器。
- 用户需要的本地执行环境随安装包交付；字体和模板等基础资源内置，新增资源从云端按需获取。
- 客户端固定六个一级入口：工作台、房源中心、AI 视频工厂、发布中心、AI 获客、设置。没有独立内容资产页面。
- 视频工厂为单页配置，只有纯口播、经纪人露脸两种模式。一次选择 N 套房源，生成一个批次和 N 个独立任务。
- 房源、视频模板和风格模板用大弹窗；提示词、声音和形象用下拉选择；文案审核可开启或关闭。
- 发布中心保留完整生产信息；同一成片的抖音、小红书任务和结果独立。平台草稿不等于正式发布。
- 首版不做套餐、支付、积分、复杂组织权限、专业剪辑时间轴、插件市场或 Redis。

## 使用规则

[原始需求讨论](https://chatgpt.com/share/6ae46246-77c0-83ee-878e-337879510e80)中较晚的用户确认覆盖较早方案。产品章节标注已确认范围，其余为实现这些需求补充的设计，不表示用户已经决定具体登录方式、供应商、操作系统最低版本或存储保留期限。

产品范围以第 01 章为准；状态、字段和接口以第 04 章为准；页面按第 03 章实现；工程边界按第 02 章实现；完成判断按第 05 章执行。出现跨章冲突应同步修正文档，不能让前端 Mock 和真实后端各用一套规则。

先完成可运行的 Mock 闭环，再逐模块接入真实能力。Mock 演示通过只说明交互可用；真实房源获取、声音克隆、数字人和平台操作必须单独验证。需要的外部能力不可用时，明确提供人工导入或待发布包等替代路径及剩余限制。

## 本地运行

当前 Windows 开发机已配置项目专用工具、数据库与账号，可直接运行 `powershell -ExecutionPolicy Bypass -File scripts/dev-local.ps1` 启动完整开发环境。地址、账号文件、检查命令和工具路径见 [Windows 本地开发环境](docs/10-local-development.md)。

开发环境使用 Node.js 24 与 pnpm 10，准确依赖版本由 `pnpm-lock.yaml` 固定。

```powershell
pnpm install
pnpm dev:web       # 浏览器预览 http://127.0.0.1:5173
pnpm dev:desktop   # 同时启动 Vite 和 Electron 桌面窗口
pnpm dev:admin     # 独立后台 http://127.0.0.1:5174
```

命令分别执行。若 `dev:web` 已占用 5173，需要先停止它再运行 `dev:desktop`。首次运行 Electron 可能下载对应版本的桌面运行时；受网络限制时可为当前命令设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`，下载仍使用 Electron 包内校验值。

管理后台仅通过独立网页 `http://127.0.0.1:5174/#/admin/dashboard` 使用，不打包进桌面客户端，桌面端也不提供后台入口。后台统一连接真实认证与 Go 服务，需要管理员登录；客户端仍可显式启用隔离的 Mock 演示。

## 已实现的前端

- 工作台、房源中心与详情，支持批量房源号、CSV、XLSX 导入以及人工添加。
- 视频工厂两种模式、跨筛选房源多选、资源选择与模拟下载、草稿即时保存。
- 一个批次多条独立任务，审核、文案历史、重生成、取消与失败重试。
- 发布中心按成果修订查看成片和记录，抖音与小红书分别设置，未知结果先核对。
- AI 获客模拟分析、话术、线索状态与跟进备注；经纪人资料、声音、形象及平台账号管理。
- 管理后台提供管理概览、用户与设备、公共模板、云端任务、只读 AI 服务状态和操作记录。支持真实分页搜索、账号支持操作、模板草稿与版本上下架；不提供假上传、假版本发布或假远程开关。
- Electron 安全壳和本地资源协议；模拟数据刷新恢复，同源多窗口写入使用 Web Locks。

所有演示操作不调用真实 AI、贝壳或社交平台。视频为本地九秒静音示例，试听为系统语音；声音/形象和媒体上传仅演示资料登记，不保存上传文件的完整字节。示例房源、客户与账号不是真实业务数据。图片来源见 [素材说明](apps/desktop/public/media/SOURCES.md)。

客户端 Mock 数据键为 `keagent.demo.workspace.v1`。旧后台演示代码已移除，遗留的 `keagent.admin.demo.v1` 数据不再读取，也不会自动删除。客户端 Mock 不是正式认证或安全隔离系统，请勿在演示模式输入真实凭据；读取损坏数据时保留原值并提示恢复，不自动清空。

客户端默认使用 `VITE_API_MODE=live` 连接真实 SDK / Go 服务，必须登录。`mock` 仅用于明确指定的客户端演示与测试，数据与云端隔离；真实模式未支持的操作返回错误。管理后台始终要求真实管理员身份，不提供 Mock 登录。开发启动顺序与账号配置见第 06 章。

真实模式的「设置 → 声音与音色」已接入本人录音上传、火山声音复刻状态、试听与用户归属管理；全景工厂可选择管理员已上架的公共音色或本人音色；露脸模式必须使用当前用户上传的照片。系统配音已实际验证；声音复刻需开通火山后付费音色并配置凭证，尚未完成真实付费联调，详见 [本人音色与系统音色](docs/11-personal-voices.md)。

## 验证与后续工作

```powershell
pnpm typecheck
pnpm test
pnpm test:e2e      # 使用本机已安装的 Google Chrome
pnpm lint         # TypeScript 与代码格式检查
pnpm build
pnpm package:desktop  # 当前系统的未签名、未压缩 Electron 前端目录
```

单元测试覆盖批量任务与幂等、审核、修订冲突及历史、独立平台状态、资源安装、持久化、CSV 解析。浏览器测试覆盖房源选择与取消、刷新恢复、三房源审核发布、导入、历史成果、多窗口写入以及 1280×800 提交入口。

本轮在 Windows 上通过 TypeScript 与格式检查、18 个单元测试、6 条浏览器场景、客户端与后台生产构建；构建后的 Electron 通过隐藏窗口实际加载验证。Mac 安装包和正式签名没有验证。

已增加 SDK 认证网关、Go 服务、PostgreSQL、云端文案接口及本机全景工作流。FFmpeg 和 Windows 系统配音已经实际生成验证；火山 TTS 与照片数字人已有云端适配器，尚未做真实付费生成验证。SQLite Sidecar、跨设备执行、平台自动化、捆绑视频运行时和正式代码签名仍未完成。当前版本不能作为完整营销系统的正式交付。

## 全景讲解开发样片

已取得两张 Poly Haven CC0 室内全景原图，均为 8192×4096 等距柱状图。来源、许可、官方校验值、分场景文案和镜头范围见 [素材清单](apps/desktop/public/media/panoramas/manifest.json) 与 [素材说明](apps/desktop/public/media/SOURCES.md)。两个地点是独立测试场景，不代表同一套或真实在售房源。

Windows 开发机已安装中文系统音色、FFmpeg 和 FFprobe 时，在仓库根目录依次运行：

```powershell
powershell.exe -NoProfile -NonInteractive -File scripts/synthesize-panorama-demo.ps1
node scripts/render-panorama-demo.mjs
```

先按每张图的分段文案生成中文配音，再探测真实音频时长，驱动全景旋转镜头、句级字幕和场景拼接。输出为 `output/panorama-demo/panorama-narrated-demo.mp4`，镜头与字幕时间记录在同目录 `timeline.json`。脚本校验源图哈希、音频与视频时长、画面实际运动及非静音音轨。

该独立样片使用本机系统 TTS 与人工核对的测试文案，不含数字人开场。现在也可在桌面端「AI 视频工厂 → 全景工作流」载入同一套 CC0 素材，完成审核和真实制作；运行 `node scripts/verify-panorama-workflow.mjs` 验证该执行器及修改镜头后的配音复用。

## 界面配色

默认主色为皇冠紫（#722ed1）。桌面端「设置 → 主题设置」、网页版后台右上角「外观设置」可切换皇冠紫、经典蓝、松石绿、玫瑰红。配色即时应用并保存在当前设备，桌面端与后台分别保存，不同步到其他设备。此功能暂不包含深浅模式或自定义色值。
