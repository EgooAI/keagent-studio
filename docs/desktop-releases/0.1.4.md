2026-11-28 版本记录

- 房源中心的「按房源号查询」支持 CLI 和贝壳浏览器两种方式。浏览器会先打开贝壳首页，再进入对应城市的房源详情页，采集页面提供的资料和 VR 链接。遇到登录或人机验证时，可直接在窗口中完成。
- 「设置 → 平台账号」会显示贝壳脱敏账号、最近一次检查结果和时间。重启后仍可查看，需要时可手动检查。
- 房源的「制作素材」可以自动从贝壳获取 VR 链接，也可以手动粘贴链接。房源没有 VR 或页面加载后仍未找到可用链接时，会给出提示。
- VR 全景图在后台下载和转换。切换房源再回来仍可查看进度，重复点击会复用当前任务，失败后可用已保存的链接重试。
- 「设置 → 软件更新与关于」支持查看新版本的更新内容，安装后也可离线查看当前版本的记录。
