# 视频制作模板管理规则

管理端的「公共模板」只显示完整视频模板。AI 视频工厂每套模板只显示版本号最高的已启用版本，支持规则版本 1 和 2。新建模板和更新旧版视频模板时使用版本 2，将整片、开场、逐图和结尾的写作规则与成片参数分开。

## 短视频带看

新增「短视频带看」和「短视频带看 · 经纪人开场」两套模板，画面样式为 `short-tour`。1.1.0 版默认竖屏 720p、30fps、1.1 倍语速，镜头基准速度每秒 36°、同图连续镜头最大转角 180°；较长镜头会降低实际速度，在整段画面内匀速完成转动。使用黄色黑边开场标题和白色黑边短字幕；字幕位于画面约 72% 高度，结尾继续展示房源画面。原有 1.0.0 版本保留每秒 8°、最大 60° 的参数，标准、经典样式保持原参数。

竖屏水平视野为 84°，垂直视野按画幅比例计算（9:16 约为 116°），封面采用相同视野。以 3 秒镜头为例，1.1.0 可转过 108°，旧版 8°/秒只转过 24°。逐图讲解与结尾使用同一张图时，共用一段连续运动，人物视频开场不占用全景图的扫角。

文案以 24–30 秒为目标，每张图只讲一个可见要点，人物开场约 2–3 秒；实际时长由生成的音频决定。标题、面积和价格来自房源资料，不能为了仿照示例补写急售、降价或业主动机。经纪人开场使用用户上传的照片、已授权的地点图和同一条配音生成，不代表真人现场拍摄。

创建任务后，可在审核页编辑两行「开场／封面标题」，逐图修改起始角度（−180° 至 180°）和旋转方向，点击「保存修改」再确认制作。该操作只修改本任务的标题、文案和镜头参数，不能替换或重排原图；人物开场不会提前推进第一个室内镜头的角度。当前预览仍是原图缩略图，需要根据全景画面校准取景。

用户可在「新建视频」及文案审核中调整配音语速（0.5–2 倍）、全景旋转基准速度（0.5–45°/秒）和最大转角（1–180°），或恢复模板默认。1.1.0 的默认值仍为 1.1 倍、36°/秒、180°。新建批次只覆盖用户明确调整的字段，其他字段分别沿用各模板默认值；空间走动模板只提供语速调整。

这些参数保存在当前任务，不修改公共模板。审核保存后，确认制作、重试和复制任务均沿用已保存值；确认制作后不能直接修改，需撤回到审核状态或复制任务后再调。语速影响配音与镜头时长，改变语速后再次制作需要重新合成配音；有 AI 人物开场时也可能重新生成开场。短视频样式在到达最大转角时会按整段时长降低实际转速。

短字幕保持原有完整句子配音，再按词组拆成最多约 12 字的显示片段；句内时间按字数分配，尚未接入逐字时间戳。只有全景图片、没有空间模型与拍摄点位时，仍只能还原相机原地旋转。本版本不添加背景音乐。

## 空间走动带看

「空间走动带看 · 经纪人开场」使用 `cameraMode: spatial`，从房源原始 VR 的三维模型、拍摄点位置与全景贴图生成镜头。相机在两个相通的真实拍摄点之间移动，产生近远物体的视差；不调用生成模型补造室内画面。

在房源资料填写如视 VR 链接后，点击素材区的「导入 VR 空间」。完整下载并校验成功后才更新这套房源的本机素材列表；既有任务、成片和原文件保留。仅支持具有模型和相通拍摄点的如视 VR，普通全景图片或不支持的链接会明确报错。

选用空间模板后，审核页可调整每张图的观察方向和「走向拍摄点」。目的地只能从原始 VR 的相通点位中选择，不能替换源空间或拍摄点。同一张图的介绍和结尾共享连续路径；人物开场不占用室内行走时长。每帧按固定时间步渲染，再复用配音、字幕和成片登记流程。缺少模型或文件校验失败时停止，不静默退回原地旋转。

空间镜头直接渲染带纹理的三维模型，避免全景图互相叠化形成重影。效果仍受原始扫描精度与点位密度限制：贴图比原始全景照片略软，遮挡边缘可能有重建变形，无法等同于现场手持实拍。渲染时需要联网打开原始公开 VR 页面，使用页面已有的相机移动接口；系统不捆绑第三方 SDK。页面失效、空间模型变更或加载失败时停止制作并提示重试。

## 管理员操作

1. 点击「新建模板草稿」直接编辑完整视频模板，或在已有模板上点击「更新版本」。
2. 填写名称、分类、适用说明和 `1.0.0` 格式的版本号。同名同版本不可重复，包括已经下架的版本。
3. 填写整片、开场、逐图和结尾的写作规则，并选择画幅、分辨率、画面样式、品牌色、字幕与镜头参数。
4. 保存后点击「预览校验」。新版模板用两张示例图生成文案，展示逐图对应关系和版式。旧版模板用示例资料填充文案。
5. 检查示例后启用该版本。版本号和内容未变时可以直接查看已保存的校验结果。修改后需要重新校验。
6. 启用后的版本内容会锁定。点击「更新版本」进入编辑页。页面顶部的「版本记录」可查看或启用历史版本。启用某个版本会同时停用同一模板的其他版本。已有任务保留原快照。

列表中的“添加规则”可随时查看以上操作说明。

## 固定制作流程

- 用户选择房源和模板后，点击“选择视频图片”，为每套房源选择 2–7 张 VR 全景图，再生成文案。可放大预览、取消重选；不足两张时需先补充素材。同一房源的多个模板共用所选图片，按素材原顺序生成文案，确认整条文案后开始制作。
- 房源镜头使用原始 VR 素材：全景模板旋转取景，空间模板沿原模型拍摄点移动，不生成或扩展房屋画面。普通照片和历史扩图不再入片；缺少 VR 素材时需在房源详情补充。
- 视频结构固定为开场、按所选图片的原顺序逐空间介绍、结尾。模板不能重排、跳过素材或新增逐段审核。
- 封面使用所选首张素材和房源标题，样式与品牌色取模板规则。镜头时长跟随配音；全景模板的最大幅度限制转角，空间模板的目的拍摄点决定移动距离。
- 正式制作把房源事实和所选 VR 全景原图发给支持 `image_url` 的多模态文案模型。户型图等参考图片参与理解，不单独出镜。模型未配置或返回漏段、重复、错序时停止，待处理后再生成文案。
- 音色按任务配置解析。露脸模板可选真人短片或 MiniMax H3 开场。MiniMax 模板保存画面提示词和地点图来源，地点图可固定上传或随房源选取。经纪人照片和配音按任务提供。
- 已有成片和历史素材记录保留；旧照片或扩图草稿不能继续生成，需补充 VR 全景图并重新生成文案。测试样例仍标明测试用途。

## 旧版变量与通用参数

| 变量              | 来源                                   | 可用位置             |
| ----------------- | -------------------------------------- | -------------------- |
| `{title}`         | 房源标题                               | 全部                 |
| `{facts}`         | 已核实的户型、面积和价格；未知值不生成 | 全部                 |
| `{sellingPoints}` | 房源卖点，无数据时使用中性说明         | 全部                 |
| `{room}`          | 当前图片对应空间名称                   | 仅空间文案，必须包含 |
| `{description}`   | 当前图片对应的已知说明，可为空         | 仅空间文案           |

开场、空间和结尾句式各为 1–1500 字纯文本。未知变量、缺失大括号及控制字符会拒绝保存。不要在模板内写死某套房源的面积、价格或学区、产权、收益承诺。不要加入密钥、外部素材链接或私人身份资料。

| 配置           | 支持值                                                   |
| -------------- | -------------------------------------------------------- |
| 语言           | 中文 `zh-CN`、英文 `en-US`                               |
| 表现           | 配音 `voiceover`、经纪人开场露脸 `avatar`                |
| 画幅、分辨率   | `9:16` / `16:9`，`720p` / `1080p`                        |
| 画面与封面样式 | 标准 `standard`、简洁 `classic`、短视频带看 `short-tour` |
| 品牌色         | 六位十六进制颜色，如 `#167D8D`                           |
| 字幕           | 开 / 关，字号标准 `standard` / 大字 `large`              |
| 配音语速       | 0.5–2 倍                                                 |
| 镜头速度       | 0.5–45 度/秒；短视频带看受最大转角限制时匀速降低         |
| 方向、最大幅度 | 右 `1` / 左 `-1`，1–180 度                               |

## 开发与兼容约定

- `ProductionTemplateRecipe` 的版本 1 保留原句式，版本 2 使用 `scriptRules` 的整片、开场、逐图、结尾规则和独立 `config`。正式新任务会把旧句式作为多模态写作提示。已保存草稿仍使用自己的模板快照。
- 使用现有 `keagent_resource` 表与管理权限、审计。`POST /v1/admin/resources` 保存或上下架；`POST /v1/admin/resources/preview` 校验已保存内容并记录该内容的预览摘要。客户端不能自行写入预览证明。
- 上架前由服务端比较当前内容摘要与已记录摘要。已发布内容不允许就地修改，同名同版本写入通过事务锁防止并发重复。
- `POST /v1/panorama/capabilities` 按模板分组，返回各组版本号最高的已上架制作模板。桌面主进程转换成能力列表。
- `POST /v1/panorama/template` 按 ID 与选择时的版本解析已上架定义。新建文案前，桌面主进程重新解析，用服务器定义覆盖界面提交的制作规则，并保存 `templateSnapshot`、`templateVersion`、房源和所选素材快照。`renderOverrides` 只允许 `rate`、`speed`、`maxSweep` 三个有限数值，在模板默认值之上应用到任务配置；其他键和越界数值拒绝提交。选图只影响新任务，不删除房源素材；任务创建后补充或修改素材不会改变已选快照。
- 文案保存时仅允许调整上述三个制作参数，其他模板规则仍锁定；模板快照保留原始默认值。后续确认生成、重试和复制使用已保存的任务配置及模板快照，不重新选择在线版本；下架不影响已有任务。
- 原有本地模板和旧草稿仍用于旧任务兼容，不作为新版工厂的新任务来源。固定的样式实现仍由本地渲染器提供，模板从受支持参数中组合，不支持上传任意渲染代码。
- 服务启动时幂等添加“标准房源带看”“卖点先行”“简洁介绍”的 1.0.0 和 2.0.0 版本。重复启动只插入缺失 ID，不覆盖管理员修改，也不会重新上架已下架的模板。

预览属于规则和版式检查，不等同于真实生成视频的视觉验收。新增模板上架前建议用测试房源确认文案，按需做一次真实成片检查；真实生成由用户在正常制作流程中明确触发。

## 房源管理与设置联调

房源中心和视频工厂不再自动添加内置测试房源（`TEST-PANORAMA-001`）。已有测试任务与成片保留，刷新不会重新出现该房源。

房源卡片、表格和详情页均提供“删除房源”。确认后删除当前账号的房源资料，并清除制作草稿与默认配置中的对应选择；已有视频、历史任务及本机素材保留。删除无法撤销，需要使用时重新录入。删除失败时保留房源并提示重试。

制作视频时录入真实房源并补充 VR 全景图，选择模板与 2–7 张图片后生成文案及视频。真实房源按后台配置使用 AI 文案和云端音色，可能产生对应费用。离线开发回归仍可运行 `node scripts/verify-builtin-factory.mjs`，其中的样例不进入用户房源列表。

用户在视频工厂选择已上架的制作模板。新视频仍可使用已保存且有效的制作偏好。比例、分辨率、文案结构、字幕和封面由模板决定；用户可调整本任务的语速、全景转速和最大转角，已有任务仍使用保存的配置和模板快照。

“设置 → 制作服务状态”显示 AI 文案、云端配音、MiniMax 开场、贝壳房源接入的配置状态，以及桌面端本机合成工具的就绪情况。供应商配置由管理员维护。

初次部署还会添加“公共讲解女声 · VV 2.0”，使用火山官方示例音色 `zh_female_vv_uranus_bigtts` 与匹配的 `seed-tts-2.0` 资源（[官方配置说明](https://docs.volcengine.com/docs/real-time-communication/configure-tts?lang=zh)）。该目录不包含密钥，仍需要服务端已配置有效语音鉴权与资源权限。管理员可在 AI 服务中下架；重复启动不会覆盖上下架状态。
