# 视频制作模板管理规则

管理端的「公共模板」只显示完整视频模板。AI 视频工厂每套模板只显示版本号最高的已启用版本，支持规则版本 1 和 2。新建模板和更新旧版视频模板时使用版本 2，将整片、开场、逐图和结尾的写作规则与成片参数分开。

## 管理员操作

1. 点击「新建模板草稿」直接编辑完整视频模板，或在已有模板上点击「更新版本」。
2. 填写名称、分类、适用说明和 `1.0.0` 格式的版本号。同名同版本不可重复，包括已经下架的版本。
3. 填写整片、开场、逐图和结尾的写作规则，并选择画幅、分辨率、画面样式、品牌色、字幕与镜头参数。
4. 保存后点击「预览校验」。新版模板用两张示例图生成文案，展示逐图对应关系和版式。旧版模板用示例资料填充文案。
5. 检查示例后启用该版本。版本号和内容未变时可以直接查看已保存的校验结果。修改后需要重新校验。
6. 启用后的版本内容会锁定。点击「更新版本」进入编辑页。页面顶部的「版本记录」可查看或启用历史版本。启用某个版本会同时停用同一模板的其他版本。已有任务保留原快照。

列表中的“添加规则”可随时查看以上操作说明。

## 固定制作流程

- 用户选择房源和模板后，点击“选择视频图片”，为每套房源选择 2–7 张 VR 全景图，再生成文案。可放大预览、取消重选；不足两张时需先补充素材。同一房源的多个模板共用所选图片，按素材原顺序生成文案，确认整条文案后开始制作。
- 仅原始 VR 全景图可进入房源视频镜头，沿用原图旋转取景，不生成或扩展房屋画面。普通照片和历史扩图不再入片；缺少全景图时需在房源详情补充。
- 视频结构固定为开场、按所选图片的原顺序逐空间介绍、结尾。模板不能重排、跳过素材或新增逐段审核。
- 封面使用所选首张素材和房源标题，样式与品牌色取模板规则。VR 全景素材使用旋转镜头。镜头时长跟随配音，最大幅度用于限制运动范围。
- 正式制作把房源事实和所选 VR 全景原图发给支持 `image_url` 的多模态文案模型。户型图等参考图片参与理解，不单独出镜。模型未配置或返回漏段、重复、错序时停止，待处理后再生成文案。
- 音色按任务配置解析。露脸模板可选真人短片或 MiniMax H3 开场。MiniMax 模板保存画面提示词和地点图来源，地点图可固定上传或随房源选取。经纪人照片和配音按任务提供。
- 已有成片和历史素材记录保留；旧照片或扩图草稿不能继续生成，需补充 VR 全景图并重新生成文案。测试样例仍标明测试用途。

## 旧版变量与通用参数

| 变量              | 来源                                   | 可用位置             |
| ----------------- | -------------------------------------- | -------------------- |
| `{title}`         | 房源标题                               | 全部                 |
| `{facts}`         | 已核实的户型、面积和价格；未知值不生成 | 全部                 |
| `{sellingPoints}` | 房源卖点，无数据时使用中性说明         | 全部                 |
| `{room}`          | 当前图片对应空间名称                   | 仅空间文案，必须包含 |
| `{description}`   | 当前图片对应的已知说明，可为空         | 仅空间文案           |

开场、空间和结尾句式各为 1–1500 字纯文本。未知变量、缺失大括号及控制字符会拒绝保存。不要在模板内写死某套房源的面积、价格或学区、产权、收益承诺。不要加入密钥、外部素材链接或私人身份资料。

| 配置           | 支持值                                      |
| -------------- | ------------------------------------------- |
| 语言           | 中文 `zh-CN`、英文 `en-US`                  |
| 表现           | 配音 `voiceover`、经纪人开场露脸 `avatar`   |
| 画幅、分辨率   | `9:16` / `16:9`，`720p` / `1080p`           |
| 画面与封面样式 | 标准 `standard`、简洁 `classic`             |
| 品牌色         | 六位十六进制颜色，如 `#167D8D`              |
| 字幕           | 开 / 关，字号标准 `standard` / 大字 `large` |
| 配音语速       | 0.5–2 倍                                    |
| 镜头速度       | 0.5–12 度/秒                                |
| 方向、最大幅度 | 右 `1` / 左 `-1`，1–180 度                  |

## 开发与兼容约定

- `ProductionTemplateRecipe` 的版本 1 保留原句式，版本 2 使用 `scriptRules` 的整片、开场、逐图、结尾规则和独立 `config`。正式新任务会把旧句式作为多模态写作提示。已保存草稿仍使用自己的模板快照。
- 使用现有 `keagent_resource` 表与管理权限、审计。`POST /v1/admin/resources` 保存或上下架；`POST /v1/admin/resources/preview` 校验已保存内容并记录该内容的预览摘要。客户端不能自行写入预览证明。
- 上架前由服务端比较当前内容摘要与已记录摘要。已发布内容不允许就地修改，同名同版本写入通过事务锁防止并发重复。
- `POST /v1/panorama/capabilities` 按模板分组，返回各组版本号最高的已上架制作模板。桌面主进程转换成能力列表。
- `POST /v1/panorama/template` 按 ID 与选择时的版本解析已上架定义。新建文案前，桌面主进程重新解析，用服务器定义覆盖界面提交的制作规则，并保存 `templateSnapshot`、`templateVersion`、房源和所选素材快照。选图只影响新任务，不删除房源素材；任务创建后补充或修改素材不会改变已选快照。
- 文案保存时锁定快照中的制作规则。后续确认生成和重试只使用任务快照，不重新选择在线版本；下架不影响已有任务。
- 原有本地模板和旧草稿仍用于旧任务兼容，不作为新版工厂的新任务来源。固定的样式实现仍由本地渲染器提供，模板从受支持参数中组合，不支持上传任意渲染代码。
- 服务启动时幂等添加“标准房源带看”“卖点先行”“简洁介绍”的 1.0.0 和 2.0.0 版本。重复启动只插入缺失 ID，不覆盖管理员修改，也不会重新上架已下架的模板。

预览属于规则和版式检查，不等同于真实生成视频的视觉验收。新增模板上架前建议用测试房源确认文案，按需做一次真实成片检查；真实生成由用户在正常制作流程中明确触发。

## 内置房源与设置联调

房源中心及视频工厂会显示一套“内置测试房源 · 全景素材”（编号 `TEST-PANORAMA-001`）。它使用已随客户端打包的两张 CC0 原全景图；来自独立客厅和酒店客房，不代表同一套真实在售房源，也没有虚构面积、价格或户型。首次使用时自动建立本机素材记录，无需贝壳鉴权或下载外部图片。内置记录不写入用户真实房源列表，刷新不会重复添加，资料与素材不可替换。

测试步骤：选择该测试房源和“标准房源带看”，在“选择视频图片”中选中两张全景图，再生成文案，确认后生成并预览、下载视频。内置测试固定使用模板句式和对应语言的本机声音，不调用收费 AI 或云端配音；中文模板需要系统安装中文声音。测试样例仅支持配音模板，露脸测试请使用本人形象与真实房源。真实房源按后台配置使用 AI 文案和云端音色，可能产生对应费用。样例成片保留测试标识，沿用正式成果登记限制，不能作为真实房源视频交接发布。离线开发回归可运行 `node scripts/verify-builtin-factory.mjs`。

用户在视频工厂选择已上架的制作模板。新视频仍可使用已保存且有效的制作偏好。比例、分辨率、文案结构、字幕、镜头和封面由模板决定，已有任务仍使用快照。

“设置 → 制作服务状态”显示 AI 文案、云端配音、MiniMax 开场、贝壳房源接入的配置状态，以及桌面端本机合成工具的就绪情况。供应商配置由管理员维护。

初次部署还会添加“公共讲解女声 · VV 2.0”，使用火山官方示例音色 `zh_female_vv_uranus_bigtts` 与匹配的 `seed-tts-2.0` 资源（[官方配置说明](https://docs.volcengine.com/docs/real-time-communication/configure-tts?lang=zh)）。该目录不包含密钥，仍需要服务端已配置有效语音鉴权与资源权限。管理员可在 AI 服务中下架；重复启动不会覆盖上下架状态。
