# 视频制作模板管理规则

后台入口：公共模板。AI 视频工厂读取已上架的完整视频模板，支持规则版本 1 和 2。新建模板和复制旧模板时使用版本 2，将整片、开场、逐图和结尾的写作规则与成片参数分开。

## 管理员操作

1. 点击“新建模板草稿”，默认即为完整视频模板；也可以复制已有模板为新版本。
2. 填写名称、分类、适用说明和 `1.0.0` 格式的版本号。同名同版本不可重复，包括已经下架的版本。
3. 填写整片、开场、逐图和结尾的写作规则，并选择画幅、分辨率、画面样式、品牌色、字幕与镜头参数。
4. 保存后，在列表点击“预览校验”。新版模板用两张示例图请求多模态文案，展示逐图对应关系和版式。旧版模板仍用本地填充的文案预览。
5. 检查示例后上架。保存后有任何内容调整，必须重新预览校验才能上架。
6. 已上架过的版本内容永久锁定，只允许上下架。调整内容必须复制新版本；新旧版本可同时上架，用户能看到版本号。确认替换完成后手动下架旧版本。

列表中的“添加规则”可随时查看以上操作说明。

## 固定制作流程

- 用户只需选择一个房源和一个模板，等待按素材顺序生成每张图片对应的文案，确认整条文案后开始制作。
- 普通照片和原始全景图可同时入片。确认文案后只对普通照片扩图，全景图沿用原图。
- 视频结构固定为开场、按原顺序逐空间介绍、结尾。模板不能重排、跳过素材或新增逐段审核。
- 封面使用首张素材和房源标题，样式与品牌色取模板规则。全景素材使用旋转镜头，扩图素材使用平移镜头。镜头时长跟随配音，最大幅度用于限制运动范围。
- 正式制作把房源事实和全部可用原图发给支持 `image_url` 的多模态文案模型。户型图等参考图片参与理解，不单独出镜。模型未配置或返回漏段、重复、错序时停止，待处理后再生成文案。
- 声音与数字人形象在任务中按用户的可用配置解析，公共模板不能绑定个人 ID。露脸模板要求用户已有可用形象。
- 扩图保留原图关联和供应商自身的水印设置。应用不在成片和封面叠加扩图提示。测试样例仍标明测试用途。

## 旧版变量与通用参数

| 变量              | 来源                                   | 可用位置             |
| ----------------- | -------------------------------------- | -------------------- |
| `{title}`         | 房源标题                               | 全部                 |
| `{facts}`         | 已核实的户型、面积和价格；未知值不生成 | 全部                 |
| `{sellingPoints}` | 房源卖点，无数据时使用中性说明         | 全部                 |
| `{room}`          | 当前图片对应空间名称                   | 仅空间文案，必须包含 |
| `{description}`   | 当前图片对应的已知说明，可为空         | 仅空间文案           |

开场、空间和结尾句式各为 1–1500 字纯文本。未知变量、缺失大括号及控制字符会拒绝保存。不要在模板内写死某套房源的面积、价格或学区、产权、收益承诺。不要加入密钥、外部素材链接或私人身份资料。

| 配置           | 支持值                                      |
| -------------- | ------------------------------------------- |
| 语言           | 中文 `zh-CN`、英文 `en-US`                  |
| 表现           | 配音 `voiceover`、经纪人开场露脸 `avatar`   |
| 画幅、分辨率   | `9:16` / `16:9`，`720p` / `1080p`           |
| 画面与封面样式 | 标准 `standard`、简洁 `classic`             |
| 品牌色         | 六位十六进制颜色，如 `#167D8D`              |
| 字幕           | 开 / 关，字号标准 `standard` / 大字 `large` |
| 配音语速       | 0.5–2 倍                                    |
| 镜头速度       | 0.5–12 度/秒                                |
| 方向、最大幅度 | 右 `1` / 左 `-1`，1–180 度                  |

## 开发与兼容约定

- `ProductionTemplateRecipe` 的版本 1 保留原句式，版本 2 使用 `scriptRules` 的整片、开场、逐图、结尾规则和独立 `config`。正式新任务会把旧句式作为多模态写作提示。已保存草稿仍使用自己的模板快照。
- 使用现有 `keagent_resource` 表与管理权限、审计。`POST /v1/admin/resources` 保存或上下架；`POST /v1/admin/resources/preview` 校验已保存内容并记录该内容的预览摘要。客户端不能自行写入预览证明。
- 上架前由服务端比较当前内容摘要与已记录摘要。已发布内容不允许就地修改，同名同版本写入通过事务锁防止并发重复。
- `POST /v1/panorama/capabilities` 返回当前已上架的制作模板；桌面主进程转换成能力列表。用户端没有本地模板兜底或个人模板混入。
- `POST /v1/panorama/template` 按 ID 与选择时的版本解析已上架定义。新建文案前，桌面主进程重新解析，用服务器定义覆盖界面提交的制作规则，并保存 `templateSnapshot`、`templateVersion`、房源和素材快照。
- 文案保存时锁定快照中的制作规则。后续确认生成和重试只使用任务快照，不重新选择在线版本；下架不影响已有任务。
- 原有本地模板和旧草稿仍用于旧任务兼容，不作为新版工厂的新任务来源。固定的样式实现仍由本地渲染器提供，模板从受支持参数中组合，不支持上传任意渲染代码。
- 服务启动时幂等添加“标准房源带看”“卖点先行”“简洁介绍”的 1.0.0 和 2.0.0 版本。重复启动只插入缺失 ID，不覆盖管理员修改，也不会重新上架已下架的模板。

预览属于规则和版式检查，不等同于真实生成视频的视觉验收。新增模板上架前建议用测试房源确认文案，按需做一次真实成片检查；真实生成由用户在正常制作流程中明确触发。

## 内置房源与设置联调

房源中心及视频工厂会显示一套“内置测试房源 · 全景素材”（编号 `TEST-PANORAMA-001`）。它使用已随客户端打包的两张 CC0 原全景图；来自独立客厅和酒店客房，不代表同一套真实在售房源，也没有虚构面积、价格或户型。首次使用时自动建立本机素材记录，无需贝壳鉴权、下载外部图片或调用 AI 扩图。内置记录不写入用户真实房源列表，刷新不会重复添加，资料与素材不可替换。

测试步骤：选择该测试房源和“标准房源带看”，等待文案，确认后生成并预览、下载视频。内置测试固定使用模板句式和对应语言的本机声音，不调用收费 AI 或云端配音；中文模板需要系统安装中文声音。测试样例仅支持配音模板，露脸测试请使用本人形象与真实房源。真实房源按后台配置使用 AI 文案和云端音色，可能产生对应费用。样例成片保留测试标识，沿用正式成果登记限制，不能作为真实房源视频交接发布。离线开发回归可运行 `node scripts/verify-builtin-factory.mjs`。

正式模式的“设置 → 默认生成配置”与后台使用相同的公共模板和公共音色列表，不再要求模拟安装资源，也不提供旧的分段审核开关。用户可设置默认视频模板、可用音色和本人形象；留空时分别为每次选模板、按语言自动选音色与按需选本人形象。新视频默认选中已保存的模板版本，配音和形象使用保存的偏好。比例、分辨率、文案结构、字幕、镜头和封面由模板决定，已有任务仍使用快照。

“刷新管理员配置”同时刷新模板、音色、本人形象和个人偏好。下架、移除或版本失配的偏好会提示重新选择；保存通过 `updateFactoryPreferences` 命令检查模板仍已上架、音色语言及本人资源归属。该命令只合并相关偏好，不覆盖旧任务或其他个人资料。服务状态只显示是否配置，不回显 API 密钥或供应商凭据。

初次部署还会添加“公共讲解女声 · VV 2.0”，使用火山官方示例音色 `zh_female_vv_uranus_bigtts` 与匹配的 `seed-tts-2.0` 资源（[官方配置说明](https://docs.volcengine.com/docs/real-time-communication/configure-tts?lang=zh)）。该目录不包含密钥，仍需要服务端已配置有效语音鉴权与资源权限。管理员可在 AI 服务中下架；重复启动不会覆盖上下架状态。
