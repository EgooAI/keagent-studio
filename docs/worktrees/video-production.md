# 视频制作 worktree 任务说明

## 目标与基线

从“成片交接契约 V1”的公共基础提交创建 `codex/video-production`。先阅读 [共享契约](../12-artifact-exchange.md)、`packages/shared-types/src/artifact.ts` 和 `packages/api-client/src/artifacts.ts`。本说明只约定制作侧如何交付成片；视频生成、编排、模型与供应商调用的具体设计在本 worktree 中另行开展。

制作侧最终交付独立的 `VideoArtifact` 和可解析的本机资产。发布侧不应需要理解 `PanoramaJob`、生产检查点或制作文件目录。

## 本侧负责

- 在真实输出完成并验证后，建立本机资产注册表，为视频、封面及可选字幕分配不透明文件令牌。
- 提供共享类型中的 `LocalMediaAssetResolver` 实现，放在独立的本机资产模块，供消费侧通过端口使用；不把解析能力藏进全景工作流类。
- 通过 `ArtifactExchange.registerAsset` 登记准确元数据，通过 `createArtifact` 登记来源版本及最小内容快照。
- 提供成片列表、详情和人工验收入口，读写共享交接接口；界面安排在现有视频工厂范围内，本说明不另定页面布局。
- 处理登记失败后的恢复：保留已完成文件及稳定请求键，重试交接登记不能触发重新生成；重做输出使用新来源版本。
- 验证文件丢失、令牌映射丢失、账号切换及设备不匹配时的行为，向共享接口报告本机可用性。

## 不属于本侧

不实现抖音账号、发布编辑、发布任务或平台请求；不在制作成功后自动发布；不读写消费侧的业务表。制作配置和过程留在制作域，交接只提交契约允许的字段。

完整制作逻辑如何设计不由本说明预设。已有全景执行器可以作为适配来源，但不能让消费侧直接引用它。

## 文件与协作边界

主要修改范围：`apps/desktop/src/components/Panorama*`、视频工厂相关页面、`apps/desktop/electron/panorama/`，以及新增的独立本机资产模块。共享文件解析端口的实现由本侧负责，发布侧使用注入适配器独立开发。

公共基础文件 `artifact.ts`、SDK、`services/cloud/artifacts.go` 及公共 JSON 夹具视为双方已冻结的契约。确需修改时先协调并合并公共提交，再让另一侧同步；不能各自改出互不兼容的字段或私有 HTTP 路径。入口文件 `auth.cjs`、`main.go` 和共享路由尽量只做小的委托注册。

## 交接验收

1. 登记真实测试文件后，另一模块只凭共享接口取得资产并通过本机解析端口访问，不需要生产任务数据。
2. 同一来源版本反复提交只得到同一成片；重新制作得到新 ID，旧成片不变。
3. 新成片初始待验收；通过、退回及并发验收符合共享修订规则。
4. 已完成文件在云端登记失败后仍可恢复登记，且不重新生成。
5. 文件缺失、错误设备或退出登录阻止后续访问，不能回退到任意路径或演示视频。
6. 共享测试和本侧必要的真实文件解析测试通过；验证无需启动抖音模块。

开发环境与建 worktree 的方式见 [并行开发准备](../13-parallel-worktrees.md)。
