# 页面与交互规范

适用范围：经纪人桌面客户端与独立 Web 管理后台。需求依据为[共享对话](https://chatgpt.com/share/6ae46246-77c0-83ee-878e-337879510e80)最后几轮确认内容。

本文的产品入口、两种视频模式、选择器类型、房源多选及独立任务规则属于已确认需求；路由、弹窗取消语义、异常状态和组件划分属于实现设计，用于统一开发与验收。文中的流程均为产品规格，不代表真实第三方能力已经接通。

## 1. 导航与视觉基础

客户端固定为六个一级入口：工作台、房源中心、AI 视频工厂、发布中心、AI 获客、设置。设置固定在侧边栏底部。不增加内容资产、资源中心、经纪人形象或会员套餐一级入口。

采用侧边栏、顶部操作栏、内容区域布局。侧边栏建议宽 220px，顶部高 60px，内容间距 24px。白色卡片配浅灰背景，蓝色强调主要操作，轻边框、适度圆角，不堆叠渐变、阴影和装饰性统计。建议基础色为背景 `#F7F8FA`、主色 `#2563EB`、正文 `#111827`、边框 `#E5E7EB`；实际文本与控件需满足可读性要求。

优先适配 1440×900，并在 1280×800 验证完整核心操作。空间不足时收缩导航或折叠详情，不隐藏提交入口。长列表及弹窗内部滚动，底部确认操作始终可见；视频保持实际画面比例。

## 2. 路由与页面职责

以下为实现路由建议；动态参数统一使用资源 ID，不使用展示标题。

| 路由 | 页面及职责 |
| --- | --- |
| `/login` | 登录、会话过期提示与重新登录 |
| `/dashboard` | 工作台、最近任务与待办入口 |
| `/properties` | 房源搜索、导入、筛选和列表 |
| `/properties/:propertyId` | 信息、图片、视频、关联任务 |
| `/studio` | 视频工厂配置主页面及批次入口 |
| `/studio/create` | 同一配置组件的新建任务入口 |
| `/studio/batches/:batchId` | 一次批量提交的任务汇总 |
| `/studio/tasks/:taskId` | 单房源任务详情、阶段与重试 |
| `/studio/tasks/:taskId/review` | 文案编辑、审核和继续执行 |
| `/publish` | 成片成果及平台发布状态 |
| `/publish/:productionTaskId` | 一份成片的来源、成果与多平台发布配置 |
| `/leads` | 获客分析任务、线索与跟进详情 |
| `/settings/:section` | 账号、经纪人、声音、形象、平台连接等分区 |

`/settings` 默认进入账号分区。`/studio/create` 复用配置组件，不能维护另一套表单。房源详情进入工厂时带入该房源，保留用户默认配置；存在未提交草稿时提示合并或替换，不静默丢弃选择。

工作台只展示能引导操作的信息：创建视频、导入房源、最近任务、待审核、待发布、本地执行器和云端连接状态。任务行点击后进入对应详情。

## 3. 房源中心

列表默认卡片，可切换表格。支持房源号、小区、标题及城市区域搜索。卡片展示封面、房源号、价格、面积、户型、素材数量、信息获取状态和发布状态，提供查看详情及创建视频入口。

导入弹窗支持单个房源号、批量房源号、Excel/CSV。批量文本按行解析，清除空行、提示重复项；文件导入允许识别房源号列并预览校验结果。提交后展示逐项进度、成功、失败和重复数量，失败项可单独重试，保留原始输入便于修改。

贝壳接入通过统一服务接口完成。接口未接通时明确展示模拟查询，真实模式提供文件导入和人工上传资料入口。不得将模拟数据标成真实查询结果。

详情分为基础信息、视频、图片、关联任务。允许核对或编辑信息，预览、添加、替换和移除素材。删除已被任务使用的素材前展示引用提示；历史任务使用快照，不能因房源资料更新而改变既有成果记录。

## 4. AI 视频工厂

### 4.1 单页配置

采用左侧约 60% 配置、右侧约 40% 预览与摘要的单页双栏布局，不使用多步骤向导。配置分组为模式与房源、模板与声音、审核及高级设置。只有“纯口播”和“经纪人露脸”两个模式。

纯口播由房源视频、TTS、字幕及封面组成；露脸模式增加经纪人数字人开场。切换模式保留房源及通用参数，仅露脸模式显示并校验形象。声音与形象分别选择，不能绑定成一个不可拆分资源。

| 配置 | 交互及必需行为 |
| --- | --- |
| 房源 | 大型多选弹窗，支持搜索、分类、分页及选择摘要 |
| 提示词 | 下拉选择，名称、简述及当前值清晰可见 |
| 视频模板 | 大型弹窗，分类、搜索、缩略图、效果预览 |
| 风格模板 | 大型弹窗，与视频模板独立选择 |
| 封面模板 | 可预览的大型弹窗，显示文字布局效果 |
| 音色 | 下拉选择，支持试听及前往设置管理 |
| 数字人形象 | 下拉选择，空状态引导前往设置创建 |
| 文案审核 | 开关，明确显示审核后继续或自动继续 |
| 字幕、字体等 | 收入高级设置，默认跟随模板 |

视频模板描述镜头结构、信息卡和片头片尾；风格模板描述字体、配色、字幕、转场和节奏。两者关联默认值可以存在，但独立更换的结果必须保留。

### 4.2 房源多选弹窗

宽度建议 1050–1150px，高度不超过窗口的 85%。顶部为搜索，分类固定为“全部、已发布过、未发布过”。房源行展示复选框、封面、名称、房源号、价格、面积、户型及素材完整性。

“已发布过”仅指存在平台确认成功发布的记录。生成过视频、提交中、平台草稿、结果待确认都不能据此标成已发布。

弹窗维护临时选择集合：跨分类、搜索和分页保留；确认后才写回表单；取消或 Escape 丢弃本次未确认修改，再次打开显示已确认值。底部固定显示已选数量、清空、取消、确认。清空只改变临时集合，仍需确认。

“全选当前筛选结果”覆盖当前查询结果快照中的全部匹配房源，不能实际只选当前页却显示全选。选择结果最终解析为明确的房源 ID，确认前展示准确数量。列表变化不自动追加新房源；选择失效或缺少必要素材时逐项提示并允许修正。

### 4.3 批量生成与资源选择

一次选择 N 套房源，提交生成一个批次和 N 条独立生产任务。所有任务使用本次统一配置，并各自保存房源、模板版本和参数快照；每条任务分别持有文案、音频、成片、封面、审核及失败原因。首版不做单房源配置覆盖。

资源弹窗共用选择组件，按类型展示分类、版本、兼容模式、内置/已下载/云端状态。未安装资源先下载、校验、安装，成功后才允许用于创建任务。失败可重试；关闭弹窗不改变已确认模板，已完成的下载可保留缓存。下载进度进入全局任务中心。

右侧展示当前模式、模板示意、已选房源数量、声音、形象、审核方式和预计任务数。未生成时标注“模板示意”或“示例预览”，不得将占位画面当成最终视频。

“保存配置”只保存草稿；“创建生成任务”校验房源、必需模板、可用音色、资源安装和露脸形象，提交期间防止重复点击。结果明确成功后进入批次详情；网络超时显示待确认并查询原请求结果，不直接再建一批任务。

## 5. 生产任务与文案审核

批次页面显示总数、进行中、待审核、完成和失败数，逐行展示房源、阶段、状态及操作。子任务独立失败或重试，不能阻断同批其他任务。只有具备真实进度来源时才显示精确百分比，否则显示当前阶段。

状态与执行阶段分开显示，使用数据契约中的统一枚举：`queued` 排队、`running` 执行中、`awaiting_review` 待审核、`succeeded` 已完成、`failed` 失败、`canceled` 已取消。阶段为 `prepare` 信息准备、`script` 文案、`tts` 配音、`avatar` 数字人开场、`render` 视频及字幕合成、`cover` 封面。审核是任务状态，字幕属于合成阶段，不另建枚举。

纯口播跳过数字人阶段。开启审核时，文案生成后停止下游处理，直到人工通过。

审核页面提供房源摘要、提示词版本、文案编辑、保存、重新生成、通过继续，以及保持待审核或取消任务。未保存离开时提示；修改冲突时保留本地文本并要求重新确认。重新生成保留此前文案版本。

已有音频或视频后修改文案，需要明确提示下游成果将失效，并通过新的生成版本重新执行；旧版本保留历史关联。不能让新文案继续引用旧配音，也不能在审核通过前提交后续阶段。

## 6. 发布中心

这里既管理发布，也承接成片查看。列表分类为全部、待发布、上传中、平台草稿、已发布、失败/待确认。生产状态与发布状态分别显示；一条成片有多个平台任务时，列表同时显示各平台结果，筛选命中任一关联平台任务即可进入对应分类。

详情大窗口使用三栏：左侧房源、提示词、模板版本、声音及形象快照；中间成片播放器、封面、文案、音频和生成记录；右侧平台、账号、标题、描述、话题、封面及发布操作。窄窗口合并为可切换分区，保留核心按钮。

抖音和小红书分别编辑标题、描述、话题及封面，分别生成发布任务，分别失败或重试。按钮说明实际目标，例如“提交到抖音草稿流程”。本地待发布、平台草稿和正式发布必须区分。

只有收到明确平台结果才展示对应成功。上传超时、回执不明时进入待确认，提供查询或人工核对，不自动重复上传。平台能力暂不支持远程草稿时，明确引导在授权平台页面完成；Mock 结果持续显示模拟标识。

## 7. AI 获客与设置

获客页左侧为分析任务及线索，右侧为选中线索详情。新建任务填写平台、视频链接、名称和分析范围。线索展示原始评论、来源、意向等级、预算、区域、户型、购房时间、AI 摘要、跟进状态和联系权限。

允许生成、编辑和复制跟进话术，匹配房源、添加备注、改变跟进状态。数据不足时显示未知，不填造预算或联系方式。首版不提供面向任意陌生用户的批量自动私信操作。

设置包含账号、经纪人资料、声音、人物形象、平台连接、默认配置、本地存储、更新与隐私授权。声音与形象独立管理，分别提供本人资料上传、授权确认、处理状态、试听或测试、默认设置和删除。正在使用的资源删除前展示影响。

平台连接展示昵称、平台、连接状态、最近检查、重新连接及解绑，不向页面暴露真实凭据。默认模板、声音、形象和审核选项用于初始化新配置；已有草稿优先，不因修改默认值而覆盖。

草稿按用户和设备保存到云端并在 SQLite 中保留镜像，恢复时优先于默认配置，切换账号时隔离各自草稿。首次连接先注册 `PlatformAccount`，再使用 `accountId` 启动本地登录；会话检查和解绑通过白名单 IPC 完成。

## 8. 全局状态与前端实现

采用 React、TypeScript、Vite、React Router、Ant Design、Tailwind CSS、Zustand、TanStack Query，图标统一使用 Lucide。复用 Ant Design 表单、弹窗、抽屉和反馈能力，不重建另一套基础控件。

TanStack Query 管理房源、资源、任务、发布、线索及设置等服务端数据；Zustand 管理会话展示、工厂草稿、选择状态、默认配置视图及抽屉开关。不要把同一份服务端列表重复存入多个 Store。真实会话与平台凭据不写入普通浏览器持久化存储。

桌面页面位于 `apps/desktop/src/renderer`，管理后台位于 `apps/admin/src`；共享类型、请求和资源协议分别进入 `packages/shared-types`、`packages/api-client`、`packages/resource-schema`。工厂拆为配置表单、房源弹窗、通用资源弹窗、声音/形象选择器、摘要、批次列表、任务详情及审核面板。

Mock 与真实服务使用相同请求响应形状，业务页面不散落环境分支。Mock 的创建、审核、下载、失败和发布都应真实更新模拟状态，并可刷新恢复；持久化数据带结构版本，不能在升级失败时静默清空用户草稿。模拟进度与真实任务标识明确分开。

顶部任务抽屉汇总导入、文案、配音、数字人、合成、资源下载、发布和获客任务，显示阶段、状态、时间、错误及详情入口。切换页面不取消任务；断线显示同步状态，重新连接后通过任务查询校正。

## 9. 独立管理后台

后台使用独立登录及路由布局，以表格和操作效率为主，与客户端共享基础视觉。建议页面为 `/admin/dashboard`、`/admin/users`、`/admin/devices`、`/admin/resources`、`/admin/ai`、`/admin/tasks`、`/admin/releases`、`/admin/settings`。

用户页管理账号状态；设备页查看连接、版本及解绑；资源页支持上传、分类、兼容性、版本、校验状态、发布和下架；AI 配置页管理供应商连接、模型、TTS、数字人和提示词；任务页查看阶段及异常；版本页管理目标平台安装包、发布记录；系统设置管理功能开关、远程配置和审计。首版不出现计费、套餐或插件市场。

客户端与后台通过同一资源服务对齐发布状态。资源管理的上传、编辑、发布按钮必须改变实际或明确标识的模拟状态，不能只有静态界面。供应商密钥只允许提交与替换，不回显原值。

## 10. 页面验收

所有页面具备加载、空数据、请求失败、断网和权限不足反馈；表单就近显示错误；耗时操作有状态、失败原因及允许的恢复入口。按钮禁用时说明原因，禁止只靠颜色表示状态。

表单有文字标签；图标按钮有可访问名称；弹窗打开正确聚焦、限制焦点在内部，关闭后回到触发按钮；支持键盘选择与 Escape 取消；中文长标题、长文案和错误信息正常换行。

必须验证的交互链路：批量导入后进入房源库；跨分类、搜索和分页选择多个房源；取消弹窗不覆盖旧选择；N 房源产生 N 个任务；模式切换保留配置；露脸缺少形象不能提交；审核阻断下游并在通过后继续；刷新恢复草稿；单任务失败不影响同批任务；同一成片两个平台独立提交；平台草稿不使房源变成已发布；未知结果不能显示成功；资源未安装不能直接执行。

在 1440×900 和 1280×800 检查以上链路、弹窗底部按钮、长列表、视频比例和键盘访问。真实外部能力的验证另列集成验收，不以 Mock 演示代替。
