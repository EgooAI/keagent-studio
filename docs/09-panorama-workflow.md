# 全景视频工作流

在桌面端打开「AI 视频工厂 → 新建视频」。云端提供房源资料、模板目录、文案及百炼配音。本机保存全景素材、审核草稿、执行检查点、配音缓存和成片，并按已登录账号隔离。

## 使用顺序

1. 选择房源，为每套房源选择 2–7 张原始 VR 全景图。
2. 应用「短视频带看」或「短视频带看 · 经纪人开场」。普通版直接从房源画面开场，经纪人版每批手动选择本机 MP4。两版共用「醒目大标题」封面和「短视频带看」文案模板，换用已上架的部件时按所选版本制作。
3. 选择管理员上架的公共音色或已就绪的本人音色，生成并审核文案。经纪人版的文案和配音从第一段房源画面开始。
4. 确认制作后，本机按配音时长渲染镜头和字幕。经纪人版先拼接开场视频并使用其原声，后接房源画面及配音。成片校验音轨、分辨率和时长后生成封面及时间轴。
5. 在制作任务中查看进度、取消、重试或预览成片。任务保存所选配置和素材快照，重试可复用符合本次输入的配音和镜头缓存。

## 开场视频库与目录同步

在「设置 → 开场视频库」保存和管理有权使用的开场视频，或在本批制作临时导入。支持 2–30 秒且不超过 50 MB 的 MP4。开场原片保存在当前账号的本机目录，临时导入只供本批选择。开场合成在本机执行，上传到云端的是生成房源文案所需的房源资料和所选图片。

新建页先读取本机模板目录缓存，再比较云端目录版本。目录变更时刷新本机列表。在后台发布的新搭配和部件会通过相同流程同步，已下架部件退出新建选项。

## 服务配置与兼容

Electron 通过认证后的 Go 接口调用文案及配音服务。管理员在「AI 服务 → 服务配置」管理多模态文案和百炼语音，在「公共音色」管理可选音色。Windows 系统音色用于独立开发样片。本人音色配置见 [本人音色与系统音色](11-personal-voices.md)。

`POST /v1/panorama/capabilities` 使用 `bundleCatalog` 获取目录，并通过 `catalogVersion` 比较版本。`script-vision` 生成房源文案，`tts` 返回合成音频。旧 MiniMax 新提交和管理测试已停用，`opening-query` 继续兼容已提交的历史任务和结算核对。

## 验证

`pnpm test` 和 `services/cloud` 下的 `go test ./...` 覆盖目录同步、版本引用、素材隔离、制作参数和任务恢复。工厂浏览器回归使用独立接口夹具，覆盖搭配替换和本机开场选择。

```powershell
pnpm test:e2e --project factory-desktop-bridge
```

Windows 开发机安装中文系统音色和 FFmpeg / FFprobe 后，可运行 `node scripts/verify-panorama-workflow.mjs`。该脚本使用两张独立的 CC0 测试全景验证本机合成和配音缓存，输出路径记录在 `output/workflow-verification/result.json`。
