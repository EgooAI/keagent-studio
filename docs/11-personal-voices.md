# 本人音色与系统音色

入口：桌面端「设置 → 声音与音色」。真实模式提供公共音色试听、本人录音上传、复刻状态查询、本人音色试听和移除。Mock 模式保留隔离的演示，不调用供应商。

全景工厂的配音服务可选择管理员上架的公共音色、当前用户已就绪的本人音色。本人音色由服务器解析为供应商音色，用户不填写供应商 ID。原有云端批次仍只执行文案阶段，此次没有扩展其下游生产能力。

## 服务端配置

```dotenv
VOLC_TTS_API_KEY=从新版火山语音控制台获取
VOLC_VOICE_CLONE_ENABLED=true
VOLC_VOICE_CLONE_RESOURCE_ID=seed-icl-2.0
```

需在火山开通声音复刻2.0及后付费自定义音色。以上凭证由服务端统一配置，不要求每位用户购买密钥或手填音色槽位。公共音色由管理员在「AI 服务 → 公共音色」新增名称、语言、火山音色编号和合成资源，并上架后提供给用户。已上架版本的音色编号、资源和语言锁定；更换需新建，避免改变历史任务。Windows 本机声音仅保留给独立开发样片脚本，正式客户端不再使用未经后台上架的设备音色。

此次采用 V3 `voice_clone` 上传、`get_voice` 查询，随后通过 HTTP 单向流式 TTS 使用 `seed-icl-2.0`。每次创建自动生成独立的自定义音色名。参考[声音复刻 V3](https://docs.volcengine.com/docs/doubao-voice/sound-replica-api-v3?lang=zh)及[开通指南](https://docs.volcengine.com/docs/doubao-voice/sound-replication-ord-erin-gand-usage-guide?lang=zh)。

## 使用与数据边界

- 上传 WAV、MP3 或 M4A，最多10 MB；界面检查时长5–30秒，推荐10–15秒清晰单人录音。服务器再次检查大小、格式标识和授权确认，最终录音质量由供应商校验。
- 用户确认授权后，录音经认证接口转发火山。业务数据库不保留录音字节，只记录本人音色、归属、授权时间、处理状态、请求指纹及供应商检查点。
- `keagent_voice` 独立表保存音色。供应商身份与临时试听链接不暴露在列表中；每次查询、试听、移除、合成都核对用户归属。
- 相同用户和请求键只提交一次，内容变化返回409。网络超时或响应异常记录“结果待核对”，通过状态查询恢复，不自动重新上传。浏览器中断后仍尽力保存提交结果。
- 试听读取供应商训练时生成的样音，先刷新临时地址，再由后端通过仅公共 HTTPS、禁止重定向的连接下载；不以系统语音冒充本人音色。
- 首次正式合成可能启用后付费音色槽位，界面在制作入口提示。移除只归档本应用记录，阻止后续制作；不会自动释放火山槽位，管理员需在供应商控制台另行处理。历史成片保留。
- 已有草稿引用被移除或尚未就绪的音色时，制作会报错并要求重新选择，不自动换成系统音色。

## 验证

```powershell
corepack pnpm lint
corepack pnpm test
corepack pnpm build
node scripts/voice-integration.mjs
```

Go 的 `voice_test.go` 覆盖文件验证、状态映射、归属、独立合成资源、超时、并发幂等及断开后的检查点。设置本机测试数据库环境变量 `ADMIN_TEST_DATABASE_URL` 后运行 `go test ./...`，数据库检查使用临时独立 schema 并在完成后清理。供应商请求由测试适配器替代，不产生付费调用。

`voice-integration.mjs` 验证真实登录、未开通提示、Electron 中的公共音色目录与本人照片限制；浏览器上传、状态及本人音色选择使用明确的接口夹具。真实声音相似度和账号权限仍需有效火山凭证完成付费联调，不能用夹具通过替代真实验收。
